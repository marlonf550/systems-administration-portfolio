# Automation Change Checklist / Lista de Verificação de Automação

- [ ] Goal and target are documented.
- [ ] Inputs contain no hard-coded secrets.
- [ ] Lowest necessary privileges are used.
- [ ] Test target is selected.
- [ ] Validation command or check is defined.
- [ ] Rollback is documented.
- [ ] Output is redacted before publication.
- [ ] Related README, inventory, and roadmap are updated.
